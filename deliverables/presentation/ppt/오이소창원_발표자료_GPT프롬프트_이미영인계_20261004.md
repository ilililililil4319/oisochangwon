# 발표자료(PPT) 만들기 — GPT 프롬프트 (이미영 님 인계)

## 작업 순서

1. GPT(ChatGPT)에 아래 **프롬프트 1**을 통째로 붙여 넣고, 같은 대화에 `오이소창원_발표자료_스크립트_20261004.md`(또는 PDF) 파일을 첨부합니다.
2. GPT가 슬라이드 10장 구성안을 주면 **프롬프트 2**로 PowerPoint 파일(.pptx)을 만들어 달라고 합니다.
3. 받은 파일을 PowerPoint(또는 Google Slides)에서 열고, 아래 **그림 넣기 표**의 그림을 해당 슬라이드에 넣습니다(GitHub에서 내려받기).
4. **확인 목록**을 보고 숫자·문구를 고친 뒤, 파일명 `오이소창원_발표자료.pptx`로 공유 드라이브에 올려 주세요(이혜경이 GitHub `deliverables/presentation/ppt/`에 올림).
5. 출처·AI 활용 신고서에 “발표자료: GPT로 슬라이드 초안 생성, 팀 검수”를 적습니다(이혜경 정리).

## 프롬프트 1 — 구성안 만들기

```
너는 공모전 발표자료 디자이너야. 첨부한 「오이소창원 발표자료 스크립트」를 그대로 따라
본선 발표용 슬라이드 10장 구성안을 만들어 줘.

[대회] 제4회 경남 AI·SW 경진대회 일반부, 사회문제 해결형 AI Agent. 발표·시연 6분 + 질의응답 2분.
발표 순서는 별지 3 기준: 문제(30초) → Agent 설명(1분) → 구조(1분) → 실제 시연(시연영상 2분 59초)
→ 성과(30초) → 발전계획·비즈니스모델(30초).

[규칙]
- 슬라이드 10장 이내, 스크립트의 슬라이드 번호·제목·순서를 바꾸지 마.
- 숫자·기능 이름·문구는 스크립트에 있는 것만 써. 새 숫자나 효과를 지어내지 마.
  (정책 24건, 할 일 26개, 생활 정보 60곳, 지역말 2,253개, 접수 창구 6단계, 자동 테스트 127개,
   팀 자체 테스트 33번·지적 83건 모두 반영, 실사용자 4명·만족도 4.75/5·추천 4/4)
- 슬라이드마다 글자는 제목 1줄 + 핵심 3줄 이내. 긴 설명은 발표자 노트(스크립트의 ‘대본’)로.
- 색: 남색 #063465(배경·제목), 주황 #FE6A01(강조), 초록 #2E9E6B(성과), 흰 바탕 카드.
  글꼴: Pretendard 또는 맑은 고딕. 젊고 깔끔한 느낌(앱 첫 화면과 같은 남색 그라데이션 표지).
- AI 모델은 ‘GPT-4.1 mini’로만 표기. 다른 모델 이름, 외부 교육 프로그램 이름은 넣지 마.
- 사람 이름은 표지에만(조준수·이혜경·이미영).

[출력] 슬라이드별로: 번호 / 제목 / 화면에 넣을 글(3줄 이내) / 넣을 그림 / 발표자 노트(대본).
```

## 프롬프트 2 — PPT 파일 만들기

```
위 구성안으로 16:9 PowerPoint 파일(.pptx)을 만들어 줘.
- 1장 표지와 10장 마무리는 남색(#063465→#0B4C8C) 그라데이션 배경, 흰 글자, 오른쪽 아래에 QR 넣을 빈 자리(4×4cm).
- 2~9장은 흰 바탕, 위에 남색 제목 띠, 강조 숫자는 주황(#FE6A01) 크게.
- 그림 자리에는 ‘[그림: 파일명]’이라고 표시한 빈 상자를 둬(내가 직접 넣을게).
- 발표자 노트에 대본을 넣어 줘.
- 파일명: 오이소창원_발표자료.pptx
```
