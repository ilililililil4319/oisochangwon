### 2. 문제 — 누구의 어떤 문제
- 제목: 창원에 막 전입한 청년, 첫 180일에 놓치는 것들
- 카드 3개: ① 혜택·할 일 정보가 여러 기관에 흩어짐 ② 혜택과 할 일에 **기한**이 있는데 언제 무엇을 할지 놓침(예: 기업노동자 전입지원금 — 전입 180일이 지나야 신청 가능) ③ 생활 정보·불편 접수 창구·지역말을 물어볼 곳이 없음
- 근거 숫자: 청년 전입 53,583명 / 전출 59,351명(2023, 창원특례시의회 정책제언 2025)

### 3. Agent 설명 — 목표와 사용자
- 제목: 나의 조건만으로 판정하고, 180일을 함께 챙기는 코디네이터 Agent
- 대상: 창원 전입 19~39세 청년(직장인·자영업·학생·기타), 대표 사용자 ‘코디2026’(28세 · 2026-09-20 전입 · 직장인 · 차량 없음)
- Goal: 실명·연락처 없이 조건(나이·전입일·사는 구·타지역 거주기간·하는 일·차량)으로 혜택 판정 → 180일 일정 → 저장·알림
- 그림: 휴대폰 `09_모바일_나의조건.jpg`

### 8. 성과 — Before / After
- 왼쪽 Before: 여러 사이트를 직접 검색, 자격은 스스로 판단, 기한은 기억에 의존
- 오른쪽 After: 조건 한 번 입력 → 4단계 판정·근거(공식 링크·확인일) → 180일 일정·캘린더·이메일 알림
- 실사용자 의견 반영 예: 조건 칸 설명 항상 표시, 생활 정보 안내·목록 돌아가기, 첫 화면·세부 화면 새 디자인

### 9. 한계와 현장 적용 전 보완점
- 정책 판정은 공고 기준 규칙 판정 → 최종 자격은 담당 기관 확인(공고가 바뀌면 다시 확인)
- 회원가입이 없어 화면을 닫으면 조건 초기화 → 캘린더·리포트로 기기 저장, 선택형 로그인 검토
- 무료 서버라 메일이 늦을 수 있음 → 캘린더 알림 함께 안내, 예약 발송 검토
- 실사용자 4명은 작은 표본 → 전입 청년·기관 담당자 대상 확대 검증
