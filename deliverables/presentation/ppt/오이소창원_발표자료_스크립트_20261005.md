### 2. 문제 — 누구의 어떤 문제
- 제목: 창원에 막 전입한 청년, 첫 180일에 놓치는 것들
- 카드 3개: ① 혜택·할 일 정보가 여러 기관에 흩어짐 ② 혜택과 할 일에 **기한**이 있는데 언제 무엇을 할지 놓침(예: 기업노동자 전입지원금 — 전입 180일이 지나야 신청 가능) ③ 생활 정보·불편 접수 창구·지역말을 물어볼 곳이 없음
- 근거 숫자: 경남 청년 순유출 10,112명(2025, 국가데이터처 국내인구이동통계) / 창원 청년(19~39세, 주민등록인구) 241,329명(2023.12) → 221,641명(2026.8) · 창원 총인구 1,009,003명(2026.8, 외국인 포함)

### 3. Agent 설명 — 목표와 사용자
- 제목: 나의 조건만으로 판정하고, 180일을 함께 챙기는 코디네이터 Agent
- 대상: 창원 전입 19~39세 청년(직장인·자영업·학생·기타), 대표 사용자 ‘코디2026’(28세 · 2026-09-20 전입 · 직장인 · 차량 없음)
- Goal: 실명·연락처 없이 조건(나이·전입일·사는 구·타지역 거주기간·하는 일·차량)으로 혜택 판정 → 180일 일정 → 저장·알림
- 그림: 휴대폰 `13_모바일_나의조건.jpg`

### 4. 핵심 기능 4개 (+ 물어보기)
