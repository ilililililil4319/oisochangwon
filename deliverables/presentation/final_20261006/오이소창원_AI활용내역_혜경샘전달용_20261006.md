# 오이소창원 생성형 AI 활용 내역 — 혜경 선생님 전달용

혜경 선생님, AI 활용 내역을 실제 사용 단계와 작업 주체별로 다시 정리해서 보내드립니다. 아래는 조준수 사용분을 중심으로 정리했으며, 다른 팀원의 사용 내역은 구분해서 반영 부탁드립니다.

> 모델 표기 기준: 과거 ChatGPT 명칭은 당시 대화 기록, Codex의 SOL·Light / Astra·Ultra와 Gemini 3.8 Flash는 조준수 확인 명칭을 기준으로 작성했습니다. Light·Ultra는 사용 설정 표기로 분리했습니다. 모든 과거 세션의 공식 모델 식별값을 별도로 검증한 내역은 아닙니다.

## 1. ChatGPT — 기획·검토 및 최종 발표자료 제작

### 업그레이드 전: GPT-5.6 Sol — 당시 사용 기록 기준
- 프로젝트 목적, 대상 사용자, 핵심 기능, 개발 우선순위와 작업 범위 정리.
- 실제 PC·모바일 캡처를 바탕으로 여백, 제목 간격, 카드·버튼 정렬, 질문·답변 배치 등 UX/UI 개선사항 분석.
- Codex에 전달할 구현·수정 지시문 작성 및 전달받은 오류·테스트 결과 검토.
- 팀 인수인계, 진행상황, 제출 서류, 출처·AI 활용 내역, 시연·발표 구성 정리 보조.

이 단계의 기획·검토와 Codex가 실행한 코드 수정·테스트는 별개의 작업으로 구분합니다.

### 업그레이드 후: ChatGPT — 현재 대화 모델 GPT-6 Astra Pro
- GitHub 발표 스크립트, 앱 코드·작업 기록, Google Drive 자료, 실제 화면 캡처를 대조해 발표 내용 정리.
- 혜경 선생님이 요청한 공식 용어, 문제 제시, LLM·규칙·도구·답변 검증·상태 저장의 역할 구분 반영.
- 제목·본문·도형·화살표를 개별 편집할 수 있는 워크플로우 중심 10장 PPT 제작 및 PDF 변환.
- 실제 앱 캡처를 활용하고 완성 시연영상의 외부 재생 링크 연결.
- 위 PPT에 맞춘 6분 발표용 대본 작성 및 Word·PDF 제작. 슬라이드별 발화 문장, 화면 설명, 전환·영상 재생 시점 정리.
- 이전 자료의 용어·수치 불일치, 과장 표현, 이미지형 슬라이드의 편집 문제를 점검하고 최종 제작물에 반영.

※ 발표 시간은 영상 길이를 반영한 목표 배분이며, 실제 낭독 시간 확정은 발표자 리허설이 필요합니다.

## 2. OpenAI Codex — 실제 코드 구현·수정·검증

### 코딩 단계: SOL / Light 사용 설정 — 조준수 확인
- Python·Streamlit 기반 앱 코드 구현·수정, 기능 연결 및 오류 수정.
- 코드 차이 확인, 컴파일·관련 테스트·전체 자동검사 실행 등 개발 검증.
- Git 커밋·푸시 및 개발 작업 기록 정리 보조.

### 최종 UX/UI 단계: Astra / Ultra 사용 설정 — 조준수 확인
- 최종 UX/UI 검토와 승인된 범위의 화면 수정.
- 헤더 제목·설명 간격, 카드 높이, 버튼 정렬, 폼 여백·중복 테두리, 모바일 화면 배치 보완.
- Ask·지역말 화면을 불편사항 화면과 같은 방식으로 정리: PC는 입력 왼쪽·결과 오른쪽, 모바일은 한 열 배치.
- 정착 일정의 월별 기본 접힘 적용, 기존 기능·저장·판정 로직 보존 여부 확인 및 수정 후 검증.

※ Codex는 작업 도구이며, SOL·Astra와 Light·Ultra는 사용자가 확인한 모델·설정 표기입니다. ChatGPT의 기획 작업과 합쳐서 하나의 개발 모델로 기록하지 않습니다.

## 3. OpenAI GPT-4.1 mini API — 실제 앱 내부 Agent

개발 보조가 아니라 오이소창원 서비스 실행 중 사용하는 모델입니다.

- 자연어 질문 이해 → 목표·의도 파악 → 필요한 도구 선택 → 도구 결과를 바탕으로 답변 구성.
- 사용자 상황, 정책, 생활정보, 지역말, 불편사항 접수 창구를 확인하는 5개 도구 중 필요한 도구를 호출.
- 정책 자격·조건 판정은 Python 규칙 엔진이 담당.
- 연락처·링크 대조, 긴급 상황 우선 안내, 오류 시 규칙 기반 안내 전환은 앱 코드의 검증·안전 절차로 구분.
- 할 일·메모·진행 상태 저장은 앱의 상태 관리 기능이며, LLM의 자율학습이나 영구 기억으로 설명하지 않음.

## 4. Google Gemini — Gemini 3.8 Flash

조준수가 확인한 모델명이며, 아래 작업은 Gemini가 전달한 수행 내역을 기준으로 범위를 정리했습니다.

- 마감 실행 브리핑, 최종 진행상황·마감계획, 인수인계 문안 등 문서 초안 작성.
- 전달받거나 조회한 프로젝트 자료·테스트 결과·수치를 비교하고 문서로 정리.
- 발표 구성안·슬라이드 초안 및 시연 시나리오·콘티 작성 보조.
- Google Drive 문서 저장 및 자료 분류·정리 보조.

Gemini가 보고한 개별 문서 생성·파일 이동은 필요시 해당 도구 실행 기록으로 확인합니다. Gemini 자체 보고만으로 공식 통계 원문 전수 검증이나 최신 저장소 직접 검증까지 확정하지 않습니다.

‘Gemini Spark’는 환경명에 대한 별도 확인 근거가 없어 제출용 모델 표기에서 제외합니다. 이번 대화에서 최종 전달한 워크플로우 중심 PPT와 발표 대본은 ChatGPT 제작물이며, Gemini의 구성안·슬라이드 초안과 구분합니다.

## 5. 그 외 발표자료 제작 도구

**NotebookLM:** 팀원이 발표자료 초안 제작에 사용한 기록이 있습니다. 최종 자료 제작 시 디자인·내용 참고자료로 활용했습니다. 세부 모델명은 확인 없이 붙이지 않으며, 조준수 직접 사용분과 팀원 사용분을 구분합니다.

**Canva:** 발표자료 가져오기·재생성·편집을 시도했으나 해당 생성본은 최종 발표자료로 채택하지 않았습니다. 필요시 ‘시안 제작·편집 시험, 최종본 미채택’으로 기록합니다.

Google Slides·Word·PDF는 열람·편집 환경 또는 산출물 형식입니다. 그 이름만으로 별도 생성형 AI 모델을 사용했다고 기재하지 않습니다.

## 6. 시연영상과 사람이 직접 수행한 작업

- 시연 화면은 실제 앱 화면 녹화이며 AI로 생성한 서비스 화면이 아닙니다.
- AI는 시연 구성, 촬영 확인사항, 자막 문구·편집 방향 검토를 보조했습니다.
- 조준수가 부족한 시연 장면을 보완하고, 최종 영상의 컷 편집·자막·속도 조절·불필요한 장면 제거를 직접 수행했습니다.
- 최종 영상 편집 프로그램의 정확한 명칭과 별도 AI 기능 사용 여부는 실제 사용 기준으로 기재합니다. 확인되지 않은 AI 음성·배경음 생성 도구를 추가하지 않습니다.
- 코드 수정 범위, 기능 유지, 화면 개선 방향, 최종 영상·발표자료의 채택은 사람이 판단했습니다. 최종 제출 승인은 실제 팀 검토 후 기록합니다.

## 7. 신고서 반영 시 꼭 구분할 사항

**기획·지시·검토(ChatGPT) / 코드 실행·수정(Codex) / 서비스 내부 모델(GPT-4.1 mini) / 문서·구성안 보조(Gemini) / 실제 촬영·최종 영상 편집(사람)**을 구분해 주세요.

기존 앱의 127개 자동검사 통과 기록을 발표자료·대본 제작 중 새로 실행한 검사로 기록하지 않습니다. 공식 통계도 이번 PPT 제작에서 원자료를 전부 재검증한 것이 아니라, 팀 확정수치 문서와 제공 자료를 대조·재인용한 범위로 적습니다.

혜경 선생님을 포함한 다른 팀원의 Claude 등 AI 사용 내역은 각자 확인한 모델명·작업 기록으로 추가하면 됩니다. 본 정리만으로 팀 전체 AI 목록이 완결됐다고 보지는 않습니다.
