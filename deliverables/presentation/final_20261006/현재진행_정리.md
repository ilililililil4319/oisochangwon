## 발표·대본에 반영된 핵심

- 서비스명: 오이소창원 / AI 기반 창원 정착 지원 Agent.
- 코디2026: 시연용 예시 사용자. Agent 이름이 아님.
- 사용자 흐름: 나의 조건 입력 → 맞춤 혜택 → 정착 할 일·일정 → 체크·메모 저장·이어보기.
- Agent 흐름: 안전 확인 → LLM 목표·의도 파악 → 필요한 도구 선택·호출 → 답변 구성 → 연락처·링크 검증 → 안내. 긴급·위기와 검증 실패는 별도 경로.
- 정책 자격은 규칙으로 판정하며, 최종 자격 판단은 담당 기관 확인. 연락처·링크 검증을 모든 답변의 사실성 보장으로 확대하지 않음.
- Memory/State는 할 일·메모·진행 상태 저장이며 LLM 자율학습·기기 간 자동 동기화와 구분.
- 검증 자료: 자동검사 127개와 점검 총 54회는 별개. 팀 자체 38회·개선 88건, 실사용자 4명·전체 만족도 4.75/5. 새로 테스트를 실행했다는 뜻이 아님.
- 문제 제시: 팀 통계 재인용. 6,616명은 2025년 창원 전체 순유출. 청년 감소의 원인이나 앱의 유출 감소 효과를 실증한 것으로 설명하지 않음.
- 지역말 뜻 안내, 불편사항 행정 접수 안내, 선택형 이메일, 캘린더 파일 저장 등 실제 구현 범위 유지.
