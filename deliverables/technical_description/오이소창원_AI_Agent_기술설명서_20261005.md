별지 1 AI Agent 기술설명서 · 2026-10-05 갱신

| 항목 | 기재 내용 |
| --- | --- |
| 팀명 / 부문 / 주제 | 오이소창원(조준수·이혜경·이미영) / 일반부 / 지정주제 01 사회문제 해결형 AI Agent(코드 10) |
| 작품명 | 오이소창원 — AI 기반 창원 정착 지원 Agent |
| 해결 문제 | 창원에 전입하고 나면 받을 수 있는 혜택과 해야 할 일에 기한이 있는데, 정보가 여러 기관에 흩어져 언제 무엇을 해야 하는지 놓치고, 생활 정보·불편 접수 창구·지역말도 물어볼 곳이 없는 문제 |
| 대상사용자 | 창원에 새로 전입한 19~39세 청년(직장인·자영업·학생·기타) |
| Agent Goal | 실명·연락처 없이 나의 조건(나이·전입일·하는 일·거주기간·차량)으로 혜택을 판정하고, 전입 후 180일 정착 일정을 만들어 저장·알림하며, 질문에는 검증된 자료로만 답함 |
| 사용 AI/LLM/모델 | 앱: OpenAI GPT-4.1 mini(`gpt-4.1-mini`, OpenAI API·이용약관, 외부 API라 가중치 미제출 — 도구 호출·답 문장 작성, 연결 실패 시 규칙 기반 안내로 자동 전환) / 개발 보조: Claude Opus 5.5(추론 수준 중간)·GPT, 10/5 UX/UI 개선 ChatGPT(GPT-5.6 Sol)·OpenAI Codex |
| 사용 Tool/API/Data/장비 | 도구 5개(get_my_situation·search_policies·search_activities·lookup_dialect·find_complaint_channel), 검증 JSON(정책 24건·할 일 26개·생활 정보 60곳·지역말 2,253개·접수 창구 6단계), SQLite, 캘린더 파일(.ics), 네이버 지도 링크, Gmail SMTP(동의 시) |
| Memory/State/Feedback 구현 | Memory: 닉네임 기준 할 일 체크·메모·저장 시각을 SQLite에 저장·복원, 같은 닉네임으로 다시 열면 남은 할 일부터 이어서 계획 / Feedback: AI 답의 연락처·링크를 검증 DB와 대조해 틀리면 다시 작성, 그래도 실패하면 규칙 기반 안내로 대체, 실행 기록을 화면에 표시 |
| 핵심 Workflow(End-to-End) | ① 나의 조건 입력 → ② 긴급·위기 문장은 AI 없이 112·119·109 즉시 안내, 그 외는 GPT-4.1 mini가 질문 목표를 인식해 도구 선택 → ③ 규칙 엔진이 정책 24건을 4단계(해당 가능·조건부·직접 확인·해당 없음) 판정 → ④ 전입일 기준 180일 정착 일정·혜택 확인일 생성 → ⑤ 도구 호출 결과로 답 작성, 연락처·링크 검증 → ⑥ 할 일 체크·메모 저장, 캘린더·정착 리포트·이메일(동의 시)로 보관 → ⑦ 다시 열면 저장 상태로 다음 할 일 계획 |
| 핵심기능 3~5개 | 1) 창원 청년 맞춤형 혜택 알림(4단계 판정·이유·지금 할 일·신청 가능 예정일) 2) 창원 생활 정보 안내 및 일정 편성(180일 일정·할 일 26개·생활 정보 60곳·캘린더·리포트) 3) 불편사항 행정 접수안내(6단계 분류·접수 창구) 4) 창원 지역말 번역(문헌 기준 뜻, 사전 밖은 짐작하지 않음) 5) 오이소창원에게 물어보기(도구 5개·답변 검증·실행 기록) |
| 기존자산 / 8일 신규개발분 | 기존자산: 서비스 아이디어·참가 신청서(9/28), 공개 자료(창원시 정책·공공 통계·국립국어원 우리말샘), 오픈소스(Python·Streamlit·python-dateutil·OpenAI SDK·SQLite) / 8일 신규개발(9/29~): 기획안, 데이터 수집·출처 검증 JSON, 앱 전체 코드(app.py·src 모듈 12개), 정책 판정 엔진, Agent 도구 루프·답변 검증, 정착 일정·저장, 캘린더·리포트·이메일 알림, 화면, 자동 테스트 127개 |
| 대표 테스트 5건 결과 | TC1 조건 입력→혜택 4·13·0·7건→할 일 저장·복원 통과 / TC2 “받을 수 있는 지원” 도구 호출·검증·공식 링크 통과 / TC3 버스 야경 추천: 검증 장소만, 차량 권장 분리 통과 / TC4 가로등→[높음] 1899-1111, 화재→AI 없이 112·119 통과 / TC5 지역말 문헌 뜻·사전 밖 “별도 확인” 통과 (TC6 범위 밖 질문 거절 포함 PC·모바일 12회 통과, 테스트 3종 총 54회: AI 자동 12회·팀 자체 38회(지적 88건 모두 반영)·실사용자 4회(만족도 4.75/5), 단위 테스트 127개) |
