## 2. 실행 방법

| 순서 | 명령 |
| :---: | --- |
| 1 | `git clone https://github.com/jojunsu98/oiso_changwon` |
| 2 | `cd oiso_changwon` |
| 3 | `pip install -r requirements.txt` |
| 4 | `streamlit run app.py` |

- 사용 환경: Python 3, `requirements.txt`(streamlit 1.64.0 · python-dateutil 2.9.0.post0 · openai 3.23.0 · anthropic 1.11.0)
- AI 키: `OPENAI_API_KEY`를 Streamlit Secrets(`.streamlit/secrets.toml`)에만 넣습니다. 저장소에는 키가 없습니다. 키가 없으면 규칙 기반 안내로 동작합니다.
- 자동 테스트: `python -m unittest discover -s tests/ai_test` → 단위 테스트 127개 통과

## 4. 역할 구분(Agent 구조)

| 구분 | 맡는 일 | 위치 |
| --- | --- | --- |
| LLM | 질문 이해 · 의도 파악 · 도구 선택 · 답변 구성 | `src/agent.py` |
| 규칙 | 정책 자격 · 조건 판정 | `src/policy_matcher.py` |
| Tool/Data | 정책 · 생활 정보 · 지역말 · 접수 창구 검증 자료 | `src/agent.py` 도구 5개, `data/` |
| 답변 검증 | 공식 연락처 · 링크를 검증 자료와 대조 | `src/agent.py` |
| Memory/State | 할 일 · 메모 · 일정 상태 관리 | `src/state_manager.py`, `storage/` |

LLM에게 모든 판단을 맡기지 않고, 정책 자격은 규칙으로 판정하며 공식 연락처와 링크는 검증 자료와 대조합니다.
