## 개발 계획서

### 과제명

오이소창원 — AI 기반 창원 정착 지원 Agent (슬로건: 창원에서 너의 내일을 응원해!)

### 과제소개

**목적.** 창원시는 청년층을 중심으로 인구 유출이 이어지는 한편 취업·학업·결혼 등으로 새 인구가 꾸준히 들어옵니다. 그러나 막 전입한 청년은 전입지원·청년정책·생활 정보가 여러 기관과 사이트에 흩어져 있어 직접 찾아야 하고, 혜택과 해야 할 일에 기한(예: 전입 후 6개월)이 있어 언제 무엇을 해야 하는지 놓치기 쉽습니다. 낯선 지역말과 불편을 어디에 말해야 할지도 정착을 어렵게 합니다. 「오이소창원」은 실명·연락처 없이 나의 조건만으로 받을 수 있는 혜택을 판정하고, 전입 후 180일 정착 일정을 만들어 저장·알림까지 이어 주는 코디네이터 AI Agent입니다. AI가 인구 문제를 직접 해결한다는 접근이 아니라, 전입 초기 정보 탐색과 생활 적응 부담을 줄이는 데 초점을 둡니다.

**개발 내용(최종 구현).** 사용자가 나이·전입일·사는 구·타지역 거주기간·하는 일(직장인·자영업·학생·기타)·차량 소지 여부를 입력하면 Agent가 상황을 판단해 필요한 기능을 실행합니다.

| 핵심 기능 | 내용 |
| --- | --- |
| ① 창원 청년 맞춤형 혜택 알림 | 정책 24건을 규칙으로 4단계(해당 가능·조건부 해당 가능·직접 확인·해당 없음) 판정, 이유·지금 할 일·신청 가능 예정일·공식 링크·확인일 표시, 차량이 없으면 K-패스 먼저 |
| ② 창원 생활 정보 안내 및 일정 편성 | 전입일 기준 180일 정착 일정(5단계)과 할 일 26개, 생활 정보 60곳(대중교통·차량 권장 구분), 체크·메모 저장, 📅 캘린더(.ics)·📄 정착 리포트·✉️ 이메일 알림(동의 시) |
| ③ 불편사항 행정 접수안내 | 불편 문장을 6단계(긴급·높음·보통·제안·마음 건강·위기)로 분류해 접수 창구 안내, 긴급·위기는 AI 없이 즉시 112·119·109 |
| ④ 창원 지역말 번역 + 오이소창원에게 물어보기 | 지역말은 핵심 30개 + 공식 출처 확장 사전 2,223개에서 문헌 기준 뜻, 사전 밖은 짐작하지 않음 / 한 문장 질문은 GPT-4.1 mini가 도구 5개를 골라 답하고 연락처·링크를 검증 |

**전체 과정.** 나의 조건 입력 → AI 분석·조건 비교(질문은 AI가 도구 선정, 혜택은 정책과 규칙으로 비교) → 검증 자료 확인 → AI 맞춤 결과 안내 → 일정 저장 및 알림(선택)의 End-to-End Workflow로 구현했습니다.

**기대효과.** 첫째, 전입 청년이 여러 기관을 따로 찾지 않고 내 조건에 맞는 혜택과 할 일을 한 화면에서 확인합니다. 둘째, 신청 기한을 캘린더·이메일 알림으로 놓치지 않습니다. 셋째, 생활 정보·불편 접수 창구·지역말까지 한곳에서 안내해 초기 적응 부담을 줄입니다. 넷째, 창원시·기관과 연계하면 경남 시군 확산(B2G)과 정착 지원 정책 자료로 확장할 수 있습니다.

### 개발 계획(실행 결과)

**개발 방법.** 자유 대화형 챗봇이 아니라 정착 과정을 관리하는 도구 기반 AI Agent로 구현했습니다. 정책 자격 판정은 생성형 AI가 아니라 Python 규칙 엔진이 하고, AI는 질문의 목표를 인식해 도구(get_my_situation·search_policies·search_activities·lookup_dialect·find_complaint_channel)를 고르고 결과를 쉬운 문장으로 설명합니다. 답 속 연락처·링크는 검증 DB와 대조해 틀리면 다시 쓰고, 실패하면 규칙 기반 안내로 바꿉니다. 데이터는 팀이 공식 출처에서 모아 검증한 JSON(정책 24·할 일 26·생활 정보 60·지역말 2,253·접수 창구 6단계)이고, 체크·메모·이메일 신청은 SQLite에 저장합니다.

**As-Is → To-Be.** 정보를 직접 찾아다니고 자격을 스스로 판단하던 방식에서, 조건을 한 번 입력하면 Agent가 혜택을 판정하고 근거(공식 링크·확인일)와 다음 행동, 정착 일정·알림까지 이어 주는 방식으로 바꿨습니다.

**기타(제외 범위).** 실제 쿠폰 지급, 자체 SNS, 1:1 멘토링, 실시간 교통정보, 외국인 체류자격 판정, 다국어 UI는 MVP 범위에서 제외했습니다. 향후 창원시·공공데이터 API 연동, 외국인 주민 다국어 정착 지원, 장기 정착 모니터링으로 확장할 수 있습니다.
