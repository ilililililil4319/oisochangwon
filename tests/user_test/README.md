## 용어

설문에서는 Agent를 **오이소창원(코디네이터 Agent)** 으로 통일해 부릅니다.

## 10/3 바뀐 점

앱이 `나의 조건 입력 → ①~④ 기능 + 오이소창원(코디네이터 Agent)에게 물어보기` 구성으로 바뀌어 설문도 맞췄습니다.

## 문항을 고칠 때 (링크 그대로)

1. https://script.google.com 에서 설문 Apps Script 프로젝트를 엽니다.
2. 코드를 모두 지우고 `oisochangwon_survey.gs` 내용을 붙여넣은 뒤 저장합니다.
3. 함수 목록에서 **`updateExistingForm`** 을 실행합니다. 지금 설문지(위 링크)의 문항만 바뀌고 링크는 그대로입니다. `setupSurveySystem` 은 새 설문지를 만드는 함수라, 실행하면 링크가 바뀝니다.
   - 응답 탭(Form Responses 1)도 새 문항 기준으로 다시 만들어 열 이름이 겹치지 않습니다.
4. 본인 휴대폰과 PC에서 1건씩 점검 응답을 낸 뒤 「분석」 탭을 확인합니다.
5. 실사용자에게 링크를 보내기 직전에 **`clearTestResponses`** 를 실행합니다. 점검용 응답이 모두 지워지고 빈 응답 탭이 새로 생겨, 실사용자 번호가 U01부터 붙습니다.
6. 3명 응답이 모이면 `buildReport` 를 실행해 결과 리포트(초안)와 「팀엑셀_옮기기」 탭을 만듭니다.

## 문제가 생겼을 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 응답 탭에 **"잘못됨: 중복된 열 이름이 발견됨"** | 문항을 지우고 다시 만들면 응답 탭에 같은 제목의 열이 또 생깁니다. 응답 탭이 표(테이블) 형식이라 열 이름이 겹치면 오류로 표시됩니다. | **`fixResponseSheet`** 실행. 응답은 지우지 않고 응답 탭만 지금 문항 기준으로 새로 만들고, 분석 탭도 다시 만듭니다. |
| 분석 숫자가 0이거나 이상함 | 응답 탭을 잘못 찾음 | `buildAnalysisDashboard` 실행(설문지와 연결된 탭을 먼저 찾음) |

## 개인정보

- 설문은 이메일 수집을 끕니다(`setCollectEmail(false)`). 응답 알림 메일은 스크립트를 실행한 담당자 계정으로만 갑니다.
- 앱의 이메일 일정 알림은 설문과 별개의 선택 기능입니다. 사용자가 직접 켜고 ‘개인정보 수집·이용’과 ‘알림 수신’에 모두 동의한 경우에만 이메일을 저장합니다. 테스트 참여자에게 켜 보라고 요청하지 않습니다.
- 표본이 3명이라 평균·비율은 참고값입니다.
