## 알려진 제약(오류 아님 — 보고서 ‘한계’에 기재)
- 배포 서버(Streamlit Cloud)가 재시작되면 저장한 체크 기록이 초기화될 수 있음(시연용 로컬 SQLite).
- AI 답변 문장은 매번 조금씩 다를 수 있음(내용·연락처·링크는 검증 단계에서 DB와 대조).
- API 키가 없거나 한도 초과 시 ‘기본 안내(AI 미연결·대체)’로 자동 전환.
