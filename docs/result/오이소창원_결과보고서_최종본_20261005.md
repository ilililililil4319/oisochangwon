## Ⅰ. 추진배경 및 필요성 → 해결 결과

### 1. 사회문제: 청년 유출과 지방의 인구소멸 위험

기획안의 경남 청년 순유출(2025년 10,112명, 20대 9,129명) 근거를 문제정의에 그대로 사용했습니다. 오이소창원은 AI가 인구 문제를 직접 해결한다고 주장하지 않고, **전입 청년의 정착 정보 부담을 줄이는 도구**로 완성했습니다.

### 2. 창원의 상황

창원 순유출(2025년 6,616명, 경남 시군 중 최다), 청년(19~39세, 주민등록인구) 241,329명(2023.12) → 221,641명(2026.8), 총인구 1,009,003명(2026.8, 외국인 포함) 등 기획안의 통계를 완료보고서(제출1)·발표자료(제출5)의 문제 설명에 같은 숫자로 썼습니다.

### 3. 왜 ‘초기 180일’인가

| 계획 | 결과 |
| --- | --- |
| 전입 후 6개월 같은 신청 시점을 대신 계산 | 전입일 기준 180일 정착 일정과 혜택 신청 가능 예정일 계산(예: 코디2026 기업노동자 전입지원금 **2027-03-20**) |
| 180일 밖 날짜 구분 | “(180일 이후)” 표시 |
| 180일은 서비스 설계 기간 | 화면·문서 모두 “서비스 설계 기간”으로 표기 |

### 4. 신규 전입 청년이 겪는 문제 → 해결

| 문제 | 구현한 해결 | 확인 결과 |
| --- | --- | --- |
| 혜택이 흩어져 있고 신청 시점을 놓침 | 나의 조건으로 정책 24건 4단계 판정, 이유·지금 할 일·신청 가능 예정일·공식 링크·확인일 | TC1·TC2 통과, 실사용자 4명 모두 ① 맞춤 혜택을 가장 유용한 기능으로 선택 |
| 차 없이 갈 곳·할 일을 모름 | 생활 정보 60곳을 지역·분야·실내·대중교통으로 거르고, 외곽은 ‘차로 가면 좋은 곳’으로 분리, 지도 검색 링크 | TC3 통과, 실사용자 ‘생활 정보 유용’ 4.75/5 |
| 불편을 어디에 말할지 모름 | 불편 문장을 6단계로 분류해 창구·연락처 안내 | TC4 통과 |
| 지역말이 낯섦 | 공식 출처 사전 2,253개로 뜻·쓰임·출처 안내 | TC5 통과 |

### 5. 기존 서비스와 차별성

기획안의 ① AI 맞춤 진단 ② 판정 설명 ③ 📅 캘린더 저장(하루 전 오전 9시 알림) ④ 📄 정착 리포트 ⑤ ✉️ 이메일 알림(선택) ⑥ 생활 정보·지역말 — **6가지 모두 구현**했습니다. 신청은 창원청년정보플랫폼·공식 사이트로 연결해 보완 관계를 유지했습니다.

## Ⅸ. 기타 → 결과

### 1. 운영 원칙

공식 출처를 먼저 확인하고 추측하지 않았으며, 10/3 이후 새 기능을 더하지 않고 대표 흐름의 안정과 화면 개선에 집중했습니다. 숫자는 최신 기준 파일과 실제 기록만 썼습니다.

### 2. 보안 유의사항

API 키·메일 비밀번호는 Streamlit Secrets에만 두었고 저장소·문서에 없습니다. 테스트 참여자는 U01~U04 코드로만 기록했고, 시연은 가상 페르소나 ‘코디2026’으로 진행했습니다. 이메일은 동의 후에만 저장하고 해지 즉시 삭제합니다.

### 3. 소통 창구

팀 회의(9/28·10/1), 단체 카카오톡방, 디스코드, GitHub, 구글 공유드라이브로 진행했고, AI 구독 한도가 차면 다음 사람이 이어받는 방식(10/1 결정)으로 끊김 없이 개발했습니다.
