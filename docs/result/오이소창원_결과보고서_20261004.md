## Ⅰ. 추진배경 및 필요성 → 해결 결과

기획안에서 정의한 전입 청년의 문제 4가지를 앱에서 다음과 같이 해결했습니다.

| 문제(기획안 Ⅰ-4) | 구현한 해결 | 확인 결과 |
| --- | --- | --- |
| 혜택이 흩어져 있고 신청 시점을 놓침 | 나의 조건으로 정책 24건 4단계 판정, 이유·지금 할 일·신청 가능 예정일(예: 기업노동자 전입지원금 2027-03-20, 180일 이후 표시)·공식 링크·확인일 | TC1·TC2 통과, 실사용자 4명 모두 ① 맞춤 혜택을 가장 유용한 기능으로 선택 |
| 차 없이 갈 곳·할 일을 모름 | 생활 정보 60곳을 지역·분야·실내·대중교통으로 거르고, 외곽은 ‘차로 가면 좋은 곳’으로 분리, 네이버 지도 검색 링크 | TC3 통과, 실사용자 ‘생활 정보 유용’ 4.75 |

‘초기 180일’은 기획안대로 **서비스 설계 기간**으로 표기했고, AI가 인구 문제를 직접 해결한다고 주장하지 않았습니다.

**기존 서비스와 차별성(기획안 Ⅰ-5) 구현 여부:** ① AI 맞춤 진단 ② 판정 설명 ③ 📅 캘린더 저장(하루 전 오전 9시 알림) ④ 📄 정착 리포트 ⑤ ✉️ 이메일 알림(선택) ⑥ 생활 정보·지역말 — **6가지 모두 구현**. 신청은 창원청년정보플랫폼·공식 사이트로 연결해 보완 관계를 유지했습니다.

검증 DB 안의 내용으로만 답하고, 금액·연락처·링크는 추측하지 않으며, 자격은 단정하지 않고 범위 밖 질문(예: 주식 추천)은 정중히 거절합니다(TC6 통과).
