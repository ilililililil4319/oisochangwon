## 기존 설문지에 반영하는 방법 (링크 그대로)

1. https://script.google.com 에서 10/2에 만든 Apps Script 프로젝트를 엽니다.
2. 코드를 모두 지우고 `oisochangwon_survey.gs` 내용을 붙여넣은 뒤 저장합니다.
3. 함수 목록에서 **`updateExistingForm`** 을 실행합니다. `setupSurveySystem` 을 실행하면 안 됩니다. 그러면 새 설문지가 생겨 링크가 바뀝니다.
   - 설문지 주소는 그대로이고 문항만 새로 바뀝니다.
   - 응답 시트 오른쪽에 새 문항 열이 생기고, 분석·리포트는 가장 최근 열을 기준으로 계산합니다.
4. 문항을 바꾸기 전에 낸 점검용 응답이 있으면 응답 탭에서 그 행을 삭제(행 번호 오른쪽 클릭 → 행 삭제)한 뒤 `buildAnalysisDashboard` 를 실행합니다. 설문지 편집 화면의 「응답」 탭에서도 지웁니다.
5. 본인 휴대폰과 PC에서 1건씩 점검 응답을 낸 뒤 「분석」 탭을 확인하고, 그 점검 응답을 지운 다음 실사용자에게 링크를 보냅니다.
6. 3명 응답이 모이면 `buildReport` 를 실행해 결과 리포트(초안)와 「팀엑셀_옮기기」 탭을 만듭니다.

## 개인정보

- 설문은 이메일 수집을 끕니다(`setCollectEmail(false)`). 응답 알림 메일은 스크립트를 실행한 담당자 계정으로만 갑니다.
- 앱의 이메일 일정 알림은 설문과 별개의 선택 기능입니다. 사용자가 직접 켜고 ‘개인정보 수집·이용’과 ‘알림 수신’에 모두 동의한 경우에만 이메일을 저장합니다. 테스트 참여자에게 켜 보라고 요청하지 않습니다.
- 표본이 3명이라 평균·비율은 참고값입니다.

이 스크립트는 작성 환경에서 구글 서비스에 접속할 수 없어 실제 구글 계정에서는 실행해 보지 못했습니다. 문법 검사와, 구글 기능을 흉내 낸 모의 실행으로 문항이 만들어지는 순서만 확인했습니다. 실행 후 점검 응답으로 꼭 확인하세요.
