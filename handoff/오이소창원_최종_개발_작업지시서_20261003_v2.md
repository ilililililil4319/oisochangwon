접수·지역말을 한곳에서 확인하고 다음 행동까지 이어갈 수 있도록 돕는 AI

작업자는 최신 main과 git status를 확인하고, 충돌이 없을 때 담당 작업을

## 12. GitHub 업로드 및 보안 지시

Push 조건: 여러 팀원이 함께 작업하므로 개인 한 명의 승인 문구를 조건으로
두지 않습니다. 각 작업자는 최신 main 확인 → git status 확인 → 담당 작업
수정 → 관련 테스트 및 전체 테스트 → 변경 내용 확인 → HANDOFF/팀 공유
갱신 후, 충돌이 없을 때 본인 작업을 commit·push합니다. 다른 팀원이 작업
중인 파일과 겹치거나 충돌 가능성이 있으면 먼저 팀에 공유하고 순서를
조정합니다.

순서: 최신 main → git status → 충돌 확인 → 작업 → 테스트 → PC/모바일
확인 → 보안 검사 → diff 확인 → commit → push → Streamlit 배포 확인.

보안 검색: sk-, OPENAI_API_KEY, API_KEY, secrets.toml, .env를 저장소
전체에서 점검하고 실제 키가 없음을 확인합니다.

개인정보: 불필요한 실명·연락처가 저장소·문서·영상·캡처에 없는지
확인합니다.
