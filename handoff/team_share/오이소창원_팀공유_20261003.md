## 4. 특이사항
1. **API 변경**: 교육용 API는 에러가 많았고, 문의 결과 대회에는 쓸 수 없다고 하여 **개인 유료 OpenAI API**로 교체 → 현재 정상 작동. 대회 후 연동(키) 삭제 예정.
2. **데이터 원칙**: 정책·생활 정보는 검증된 것만 사용. 지역말은 신뢰도 높은 공식 출처로만 확장.
   - 테스트 중 에러: 사전에 없는 단어를 물으면 AI가 상황에 맞지 않는 시청 전화번호를 안내함.
   - 실시간 웹 검색은 에러·미검증 단어 위험이 있어 쓰지 않음 → 사전 확장 + 없는 단어는 **“별도 확인 필요” + 국립국어원 우리말샘 링크**로 대체.
3. **카카오톡 링크 미리보기**: 캐시를 삭제해도 예전 화면이 남아 있었음(“캐시 삭제로 해결”이라고 기록하지 않음). 배포 확인은 **실제 휴대폰 Chrome/Safari(시크릿 모드)**에서 배포 주소로 직접 확인하는 것을 기준으로 함.
4. **작업 환경**: 같은 요청이 여러 창에서 동시에 실행되어 같은 파일이 겹쳐 수정된 일이 여러 번 있었음 → **작업 창은 하나만** 사용.
