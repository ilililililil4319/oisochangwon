## 2. 이메일 알림 오류 — 팀장님(조준수) 처리 요청
| 항목 | 내용 |
| --- | --- |
| 증상 | 배포 앱에서 이메일 알림 신청 시 “(오류: 587 로그인 SMTPServerDisconnected / 465 로그인 SMTPServerDisconnected)” |
| 진단 | Gmail 서버 연결·암호화는 성공, **로그인 순간 Gmail이 연결을 끊음** → 앱 코드·포트 문제 아님. 해외 클라우드(Streamlit) 서버에서의 첫 로그인을 Google이 의심 접속으로 막았을 가능성이 큼 |
| 지금 동작 | 실패하면 신청을 취소하고(이메일 저장 안 함) “📅 캘린더에 저장으로 알림 받기”를 이메일 칸 바로 아래에 안내. 캘린더·리포트·나머지 기능은 정상 |

**해결 순서(팀장님 Gmail `whwnstn9294`)**
1. Google 계정 → 보안 → **최근 보안 활동**: “차단된 로그인 시도/의심스러운 활동” 알림이 있으면 **“본인 맞음”**으로 허용
2. 같은 보안 화면에서 **2단계 인증 켜짐** 확인
3. **앱 비밀번호 새로 만들기**(16자리) → share.streamlit.io → oisochangwon ⋮ → Settings → Secrets에서 `SMTP_PASSWORD` 값만 교체 (**`OPENAI_API_KEY`는 지우지 않기**, 키는 단톡·GitHub·문서에 붙이지 않기)
4. Manage app → **Reboot** → 정착 일정 → ✉️ 이메일 알림 신청 → 본인 메일로 신청
5. 결과: 메일(캘린더 파일 첨부)이 오면 성공. 실패 안내 끝 “(오류: …)” 문구를 이혜경에게 전달
6. 그래도 안 되면: 이메일 알림은 ‘준비 중’으로 두고 캘린더 알림만 사용(대회 필수 기능 아님)

- 키·비밀번호는 Streamlit Secrets에만. 코디세이 언급 금지, 캡처의 옛 AI 모델 이름 블러

- md→pdf·docx 변환 도구: `handoff/tools/`(`regen_all.sh` 한 번에 다시 만들기, 제출 서류 첫 쪽 QR 자동 삽입, Word는 한글 어절 단위 줄바꿈)
- README 한글 끊김 방지: GitHub는 한글을 글자 단위로 줄바꿈해서, README 글자 사이에 보이지 않는 결합 문자를 넣어 둠. README를 고치기 전 `python handoff/tools/keepall_md.py --strip README.md`, 고친 뒤 `python handoff/tools/keepall_md.py README.md`
