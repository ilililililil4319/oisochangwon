| `regen_all.sh` | 모⁠든 제⁠출·공⁠유 문⁠서⁠를 md에⁠서 PDF·Word로 다⁠시 만⁠들⁠기(첫 쪽 로⁠고·QR, 쪽 번⁠호) |
