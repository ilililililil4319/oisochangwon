## AI 모델 연결(API 키)

키는 코드·GitHub에 넣지 않습니다. Streamlit Cloud → 앱 Settings → Secrets 또는 로컬 환경변수에 넣습니다.

```toml
ANTHROPIC_API_KEY = "sk-ant-..."   # 또는 OPENAI_API_KEY = "sk-..."
# 선택: LLM_PROVIDER = "anthropic" / LLM_MODEL = "claude-haiku-4-5-20251001"
```

키가 없거나 오류가 나면 앱은 ‘기본 안내(키워드 규칙)’로 자동 전환됩니다.

## 날짜 계산

정착 계획은 전입일로부터 0, 7, 30, 90, 180일 경과 시점을 표시합니다. P01의 6개월 거주 조건은 180일 고정이 아니라 달력 기준 6개월로 계산하므로 두 날짜가 다를 수 있습니다.

## 미션 데이터

`data/missions.json`은 `oisochangwon_handoff_20261001.zip`의 `handoff_20261001/data/missions.json` 원본을 그대로 복사한 파일입니다. 26개 항목은 `ID`, `개월`, `월별 테마`, `미션`, `난이도(쉬움/보통)`, `연결 기능`, `완료 기준`, `메모`, `is_service_idea`, `서비스 목표` 필드를 가집니다.

`mission_manager.py`가 JSON 구조, 선언된 건수, 필수 필드, ID 중복 및 월별 테마 일관성을 확인합니다. 앱은 원본 ID를 진행 상태 키로 사용하고, 미션을 `개월`과 `월별 테마` 기준으로 접힌 월별 그룹에 표시합니다. JSON에 일 단위 마감일은 없으므로 미션에 임의 날짜를 부여하지 않습니다. `연결 기능`은 데이터의 분류 정보이며 외부 기능을 실행하지 않습니다.

## 미션 진행 상태

미션 체크 상태는 `storage/progress.sqlite3`에 로컬로 저장됩니다. 저장 폴더와 SQLite 파일은 앱 사용 시 자동으로 생성됩니다. `mission_progress` 테이블은 `nickname`, `mission_id`, `completed`, `updated_at`을 저장하고 `(nickname, mission_id)`를 복합 기본키로 사용합니다. 닉네임 앞뒤 공백은 제거해 사용자 키로 사용하며, 같은 닉네임으로 다시 열면 저장된 상태를 불러옵니다. 닉네임은 인증 수단이 아니므로 이 저장 기능은 단일 로컬 사용자 환경을 위한 것입니다.

기존 미션 ID로 저장된 행은 삭제하거나 새 ID에 임의 연결하지 않습니다. 새 미션은 JSON의 `ID`를 사용합니다.

## 전체 E2E 흐름

프로필 입력 → Python 규칙 기반 P01 판정 → D+0/7/30/90/180 경과일 표시 → 원본 월별 미션 및 완료 기준 표시 → 체크 상태를 SQLite에 저장 → 같은 닉네임으로 다시 열어 상태 복원.

## 링크 신뢰도

원본 자료는 변경하지 않았습니다. `activity_manager.py`의 정확한 호스트 허용목록으로 58개 출처 링크를 분류합니다. 공공기관·공공 안내 16건과 운영주체 공식 사이트 15건 중 HTTPS 인증서가 유효하지 않은 창동예술촌 A40을 제외한 14건, 총 30건만 공식 안내로 연결합니다. 예약 경로라 확인되는 주소는 예약·이용 안내로 표시합니다.

제3자 링크 21건은 공식 안내에서 숨깁니다: 언론 4건(A83, A321, A326, A327), 장소·상업 디렉터리 14건(A209, A311–A320, A322, A324, A325), 위키백과 1건(A98), Facebook 1건(A126), 블로그 1건(A323). 도메인 운영주체를 확인하지 못한 A134, A136, A310의 링크도 숨깁니다. 원본에 공식 주소가 없는 A56, A108, A215는 링크를 만들지 않습니다.

2026-10-02에 원본의 54개 고유 HTTP(S) 주소에 읽기 전용 접속 확인을 수행했고 모두 최종 2xx 응답을 받았습니다. 응답 가능 여부만으로 공식성을 인정하지는 않습니다. 공식 안내로 사용하지 않는 기존 URL 24건은 화면에서 숨겼으며 원본 파일은 바꾸지 않았습니다.

## 네이버 지도

이동 버튼은 [네이버 지도에서 보기](https://map.naver.com/p/) 하나이며 데스크톱·모바일 모두 HTTPS 웹 화면을 엽니다. 지도 검색창에 위 장소명을 입력해 주세요. 앱 설치가 필요한 `nmap://` 버튼은 사용자 화면에서 제거했습니다.

공식적으로 문서화된 웹 검색어 전달 규격을 확인하지 못해 검색 URL이나 place ID를 추정하지 않습니다. 검증된 주소·좌표도 없어 경로를 미리 만들지 않습니다. 장소를 확인한 뒤 현재 위치를 출발지로 선택해 길찾기를 시작해 주세요. 원본 활동 자료와 공식 출처 검증은 유지합니다.

## 1~6개월 정착 여정

지원과 할 일을 확인하면 1~6개월 차의 제목이 모두 표시됩니다. 현재 단계에는 ‘지금’을 붙이고 기본으로 펼치며 나머지는 접습니다. 제목을 눌러 과거·미래 단계도 열 수 있습니다. 체크·내 기록·단계 저장 방식과 SQLite 구조는 유지하며 전입일을 바꿔도 기록은 같은 미션 ID로 복원합니다.

## 2026-10-02 중단 작업 안정화

- `data/mission_resources.json`의 18개 미션 리소스를 기존 미션 화면에 연결했습니다. 실제 미션·활동 ID, 중복, 필수 필드, 날짜 형식과 공식 HTTPS 호스트를 검증합니다. 신청 URL과 장소 URL에도 같은 기준을 적용합니다.
- 창동예술촌은 HTTP만 접속 확인됐고 HTTPS는 인증서 검증에 실패했습니다. 주소는 `withheld_links`에 보존하며 미션과 활동의 공식 버튼을 숨깁니다. 최신 클래스·플리마켓 일정, 축제·홈경기 일정과 접근이 차단된 청년공간 상세는 확인 필요 상태로 유지합니다.
- 거주 구 기본값은 ‘지역을 선택해 주세요’이며 선택한 구만 활동 필터에 반영합니다. 동네는 선택 입력입니다.
- Copilot이 남긴 단계별 메모·체크 저장과 사이드바 진행률을 보존했습니다. 체크와 메모는 ‘이 단계 저장하기’를 눌러 저장하며, 같은 닉네임으로 복원합니다. 기존 SQLite 데이터는 메모 열을 추가하면서 보존합니다.
- 일부 창원시 청년 페이지는 이번 접속에서 HTTP 403이 반환됐습니다. 공식 도메인 판정과 현재 접근 가능 여부는 별개이며 전체 링크의 실시간 정상 접속을 보장하지 않습니다.
