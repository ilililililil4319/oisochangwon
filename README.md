## 1. 핵심기능

| 기능 | 하는 일 |
|---|---|
| ① 창원 청년 맞춤형 혜택 알림 | 나의 조건(나이·전입일·하는 일·타지역 거주기간·차량)과 정책 24건을 비교해 4단계(해당 가능·조건부 해당 가능·직접 확인·해당 없음)로 안내, 신청 가능 예정일·공식 링크·확인일 표시 |
| ② 창원 생활 정보 안내 및 일정 편성 | 전입일 기준 정착 일정과 1~6개월 할 일 26개(체크·메모 저장), 생활 정보 60곳(구·분야·실내 필터, 대중교통/차량 구분, 네이버 지도 검색 링크) |
| ③ 불편사항 행정 접수안내 | 불편을 6단계(긴급·높음·보통·제안·마음 건강·위기)로 판단해 창구 안내, 긴급·위기는 AI 없이 즉시 112·119·109 |
| ④ 창원 지역말 번역 | 핵심 30개 + 공식 출처 확장 사전 2,223개에서 ‘문헌 기준 뜻’ 안내, 사전 밖 단어는 “별도 확인 필요” + 국립국어원 우리말샘 링크 |
| AI 코디에게 물어보기 | Agent 입구: 한 문장 질문 → AI가 도구 5개 중 선택·호출 → 답변 검증 → 답 + 관련 공식 링크 + Agent 실행 기록 |

## 3. 실행 방법

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

### AI 모델 연결(API 키)
키는 코드·GitHub에 넣지 않습니다. Streamlit Cloud → 앱 Settings → Secrets(또는 로컬 환경변수)에 한 줄만 넣습니다.

```toml
OPENAI_API_KEY = "sk-..."
```

키가 없거나 오류가 나면 ‘기본 안내(키워드 규칙)’로 자동 전환되고, 원인은 ‘Agent 실행 기록’에 남습니다(키 값은 가림).

### 테스트

```powershell
python -m unittest discover -s tests -v
```

## 4. 데이터·안전 원칙

- 정책·생활 정보는 팀이 공식 출처로 확인한 데이터만 사용하고 확인일·공식 링크를 함께 표시합니다. 지원 대상 여부는 단정하지 않습니다.
- AI 답변 속 연락처·링크는 도구 결과(검증 DB)와 대조하고, 없는 값이면 다시 쓰게 하거나 규칙 기반 안내로 바꿉니다.
- 지역말은 국립국어원(우리말샘 등)·경남방언사전·디지털창원문화대전 출처만 사용합니다. 실시간 웹 검색은 쓰지 않습니다.
- 정착 일정은 전입일로부터 0·7·30·90·180일, 기업노동자 전입지원금은 달력 기준 6개월로 계산합니다(두 날짜는 다를 수 있음). 180일 밖 날짜는 “(180일 이후)”로 표시합니다.
- 할 일 체크·메모는 `storage/progress.sqlite3`(로컬 SQLite)에 닉네임 기준으로 저장합니다. 배포 서버 재시작 시 초기화될 수 있습니다(시연용 한계).
- 상업 시설은 특정 업체 홍보가 아니며 방문 전 운영시간 확인을 안내합니다.
