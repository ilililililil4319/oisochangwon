## 1. 무엇을 하나요

| 기능 | 내용 |
|---|---|
| ① 창원 청년 맞춤형 혜택 알림 | 나의 조건(나이·전입일·하는 일(직장인·자영업·학생·기타)·타지역 거주기간·차량 유무)과 정책 24건을 비교해 4단계(해당 가능·조건부 해당 가능·직접 확인·해당 없음)로 판정. 신청 가능한 이유 / 안 되는 이유·지금 할 일·신청 가능 예정일·공식 링크·확인일 표시 |

| 오이소창원에게 물어보기 | 4개 기능을 잇는 코디네이터 Agent 입구. 한 문장 질문 → 도구 5개 중 선택·호출 → 답변 검증 → 답 + 관련 공식 링크 + Agent 실행 기록 |

### 기존 서비스와 다른 점

창원청년정보플랫폼이 정책 게시·신청 중심이라면, 오이소창원은 AI가 나의 조건으로 **실제 판정해 4단계로 분류하고 이유와 지금 할 일을 설명**합니다. 그 결과를 **📅 내 캘린더**(휴대폰에서 저장하면 내 달력에 일정과 하루 전 알림)와 **📄 정착 리포트**(정착 할 일과 혜택 신청 가능일을 시간 순서로, 공식 자료 링크 포함)로 남기고, **✉️ 이메일 알림**은 원할 때만 동의 후 보냅니다. 신청은 플랫폼·공식 사이트로 연결합니다(보완 관계).

- 실명·연락처는 받지 않습니다(닉네임과 조건만). 할 일 체크·메모는 닉네임 기준으로 저장됩니다.
- 시연 예시: ‘코디2026 예시로 둘러보기’(28세, 2026-09-20 전입, 타지역 2년, 직장인, 차량 없음). 앱은 빈 칸으로 시작합니다.

## 2. Agent 동작 흐름

```
한 문장 질문
 → ① 안전 확인: 긴급(112·119)·위기(109)는 AI를 거치지 않고 바로 안내
 → ② 목표 인식: GPT-4.1 mini가 필요한 도구 선택
 → ③ 도구 호출: get_my_situation · search_policies · search_activities · lookup_dialect · find_complaint_channel
 → ④ 답변 검증: 답 속 전화번호·링크가 도구 결과(검증 DB)에 있는지 대조, 없으면 1회 다시 작성
 → ⑤ 결과: 답 + 관련 공식 링크 + Agent 실행 기록
 → (연결 실패·검증 실패) 규칙 기반 안내로 자동 전환
```

### AI 모델 연결(API 키)
키는 코드·GitHub·문서에 넣지 않습니다. Streamlit Cloud → 앱 Settings → Secrets(로컬은 환경변수)에 한 줄만 넣습니다.

```toml
OPENAI_API_KEY = "sk-..."
```

### 이메일 일정 알림(선택 기능)
보내는 메일 계정도 Secrets에만 넣습니다. 두 줄이 있어야 신청 칸이 열리고, 없으면 이메일을 받지 않고 캘린더 파일만 안내합니다. Gmail은 2단계 인증을 켠 뒤 만든 **앱 비밀번호**(16자리)를 씁니다. 평소 로그인 비밀번호는 넣지 않습니다.

```toml
SMTP_USER = "보내는 Gmail 주소"
SMTP_PASSWORD = "앱 비밀번호 16자리"
```

Gmail이 아닌 메일은 `SMTP_HOST`, `SMTP_PORT`(587 또는 465)도 넣습니다. 보내는 사람 표시를 바꾸려면 `SMTP_FROM`을 넣습니다.

키가 없거나 오류가 나면 ‘기본 안내(키워드 규칙)’로 자동 전환되고, 원인은 ‘Agent 실행 기록’에 남습니다(키 값은 가림).

## 5. 데이터·안전 원칙

- 정책·생활 정보는 팀이 공식 출처로 확인한 데이터만 쓰고, 확인일·공식 링크를 함께 보여 줍니다. 지원 대상 여부는 단정하지 않습니다.
- AI 답변 속 연락처·링크는 검증 DB와 대조합니다. 없는 값이면 다시 쓰게 하거나 규칙 기반 안내로 바꿉니다.
- 지역말은 국립국어원(우리말샘 등)·경남방언사전·디지털창원문화대전 출처만 씁니다. 실시간 웹 검색은 쓰지 않습니다.
- 정착 일정은 전입일로부터 0·7·30·90·180일, 기업노동자 전입지원금은 달력 기준 6개월로 계산합니다(두 날짜는 다를 수 있음). 180일 밖 날짜는 “(180일 이후)”로 표시합니다.
- 이메일은 사용자가 ‘✉️ 이메일 알림 신청’을 누르고 개인정보 수집·이용과 알림 수신에 모두 동의한 경우에만 `storage/alerts.sqlite3`에 저장합니다. 마지막 알림 뒤 또는 해지(앱 안 해지 칸·메일 속 해지 링크) 즉시 삭제합니다. 상시 스케줄러가 없어 신청 즉시 전체 일정(.ics 첨부, 하루 전 알림)을 보내고, 하루 전 알림 메일은 앱이 실행될 때 보냅니다.
- 캘린더 파일·정착 리포트에는 실명·연락처·닉네임이 들어가지 않고 사용자 기기에만 저장됩니다.
- 할 일 체크·메모는 `storage/progress.sqlite3`(로컬 SQLite)에 저장합니다. 배포 서버가 재시작되면 초기화될 수 있습니다(시연용 한계).
- 상업 시설은 특정 업체 홍보가 아니며, 방문 전 운영시간 확인을 안내합니다.
